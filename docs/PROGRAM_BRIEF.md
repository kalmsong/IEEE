# 공모전 개요

**확인일:** 2026-11-12  
**상태:** 공식 모집 페이지 기준 요약. 변경될 수 있으므로 최종 제출 전 재확인.

## 목적

IEEE Humanitarian Technologies와 UNDP가 실제 도시의 문제를 오픈소스 생성형 AI로 해결할 팀을 모집한다. 도시와의 공동 기획, 시제품 개발, 현지 실증으로 이어지는 지원 프로그램이다. 일반적인 AI 이미지·디자인 생성 경연이 아니다.

## 세 도시

| 도시 | 문제 | 주요 사용자 | 필요한 산출물 |
|---|---|---|---|
| Skopje (북마케도니아) | 인허가·조경문서 변경사항이 녹지대장에 늦게 반영됨 | 녹지대장·GIS 담당자 | 수목 변경정보 추출, 공간정보 매칭, 검토·승인된 GIS 갱신 제안 |
| Rivne (우크라이나) | 건물주·공동주택 대표가 에너지 개선방법·비용·재원을 판단하기 어려움 | 주민, 공동주택 대표, 소상공인, 시 자문관 | 건물 프로필, 개선안 비교, 개략 비용·효과, 보고서 |
| Pristina (코소보) | 교통·시민 의견이 여러 출처에 분산됨 | 대중교통 계획자 | 데이터와 의견을 통합한 노선 검토 보조 |

하나의 팀은 **하나의 도시 과제**를 선택해 제안한다.

## 첫 제출물

1. **서술형 제안서**: 도시 과제 이해, 구체적 구현 방안, 기술·데이터 구조, GENIE 사용 계획, 책임·검증, 팀 실행 역량을 IEEE Funding Portal에 제출.
2. **Zindi 기술시험**: 제공된 문서·표·공간정보에서 질문별 답변과 근거를 생성하는 재현 가능한 AI 분석 프로그램을 구성하고 결과 파일을 제출.

**도시용 프로그램 전체 구현은 1차 접수의 필수조건이 아님.** 단, Zindi 기술시험에는 실제 작동하는 분석 코드가 필요하다.

## 선발 및 지원

- 기술시험 상위권(잠정 100팀) 중 검증을 거쳐 제안서 심사.
- 최대 20팀 공동 기획 → 도시별 3팀(총 9팀) 시제품 단계 → 도시별 1팀(총 3팀) 실증.
- 최종 수상팀의 지원금은 시제품 단계 $10,000 + 현지 시범단계 최대 $30,000, 총 최대 $40,000.
- 1차 마감: **2026-12-13 23:59 미국 동부시간 (EST), 한국시간 2026-12-14 13:59**.
- 팀: 18세 이상 개인 2명 이상, 법인 단독 참가 불가. Zindi 기술시험 팀은 최대 4명.

## 평가 방향

공식 제안서 심사: 도시 과제 적합성 20%, 기대효과 25%, 팀 역량 20%, 기술 접근·실현가능성 35%. Zindi 시험은 별도 점수 평가.

## GENIE 규정

IEEE 공식 모집페이지(2026-11-12 확인)는 **모든 팀이 GENIE.AI를 사용해야 한다**고 명시한다. 1차 서술형 제안서에는 활용 계획을 설명하면 되고, Zindi 기술시험에 GENIE를 사용할 필요는 없다고 별도 표기한다. **GENIE 의무 범위·타 프레임워크 병행 허용범위는 최종 지원 시 FAQ/주최 측에 재확인 권고.**

**구현 전략:** 모델 자체를 새로 학습시키는 제안이 아니라, 오픈소스 LLM+문서 검색+전문 API+인간 검수+도시 UI를 결합한 업무 시스템을 제안한다. Zindi용 3B 이하 모델 제한은 도시 시제품에 자동 적용되는 규정이 아니다. [세부 Q&A·사전 테스트 계획](GENIE_QA_AND_TEST_PLAN.md).\n\n## 출처

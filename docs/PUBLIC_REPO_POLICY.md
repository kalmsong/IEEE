# 공개 저장소 운영 원칙

`kalmsong/IEEE`는 **public** 저장소입니다. 일반 사용자가 파일 내용을 열람·복제할 수 있다는 점을 전제로 운영합니다.

## 올릴 수 있는 것

- 직접 작성한 공개자료 요약·분석 메모, 링크 목록, 회의 기록, 킥오프 HTML 목업.
- 공개가 허용된 일반적인 분석 코드·시각화 코드(기존 회사·서비스 지식재산권과 분리).
- 모델·데이터·라이브러리의 공개 라이선스를 확인한 후 적절히 귀속 표시한 자료.

## 올리지 않을 것

- AIRTECT 관련 **운영 서버 코드 전체, 비공개 DB 덤프, 프로젝트 고객/사용자 데이터, 환경변수, 인증 토큰, API 키**.
- 제3자 저작권을 확인하지 못한 PDF 원본·현지 도시 자료·기사 사진.
- Zindi Train/Test 원본·원천 소스·제출물 중 라이선스와 재배포 조건을 검토하지 않은 자료.
- 시험용 정답, 비공개 평가 정보 또는 타 팀의 비공개 접근 자료.

## 라이선스

현재 본 저장소에 **LICENSE 파일을 자동 부여하지 않았습니다.** 공개 저장소(public)와 사용·수정·배포를 허용하는 오픈소스 라이선스는 다른 개념입니다. 공모전 최종 제출용 프로젝트에는 요구된 범위의 퍼미시브 라이선스를 별도로 선택하고, 기존 기밀 코드와 명확히 분리해야 합니다.

## 커밋 전 점검

- 비밀·개인정보·클라이언트/사내 기밀이 없는가?
- 파일/이미지/데이터 재배포 라이선스가 확인되는가?
- 사실/가정/계획/미검증을 구분했는가?
- 데이터셋 Train/Test 분리와 시험 규정을 위반하지 않는가?

# 도시별 과제 분석 — Skopje / Rivne

**기준:** IEEE 공식 과제 PDF, 2026-11-10 확인.  
**중요:** 실제 시범지역 자료의 완성도·접근권한·형식은 추후 협의 예정. 공개 서비스와 확정 제공 데이터를 혼동하지 않는다.

## Skopje — Green Infrastructure AI Assistant

**문제:** 부서마다 흩어진 건축허가·수목제거 승인·조경 문서에서 수목 변경이 발생하지만 기존 Green Cadastre(GIS 녹지대장)에 지연 반영됨.

**MVP(필수)**
1. 스캔 PDF·Word 등에서 기존 수목, 승인된 제거, 대체 식재, 이행 의무 추출. 대부분 마케도니아어. CAD는 샘플 테스트 후 지원 여부 확정.
2. 추출정보를 위치·기존 GIS 레코드와 매칭, 불확실성 표시, 공간 갱신안 제시.
3. 일반 문장 질문에 대해 녹지대장과 검수된 문서를 바탕으로 근거를 붙여 답변.
4. 근거 문서 제시 → 담당자 수정 → 승인 후 갱신. AI가 허가·단속을 자동 결정하지 않음.

**선택 기능:** 열섬·생태지도 통합 영향요약, 우선 식재지도, 광역 시역 확장.

**데이터 상태:** 공공 GIS 서비스·열섬 지도는 존재. 시범 구역의 정확한 추출본, 최신성·커버리지·허가서 샘플, CAD/수량산출서, 수목 식재 확인 기록은 제공 범위 협의 필요. 주민용 첫 버전 없음.

**구현상 난제:** 스캔·다국어 문서 추출 정확도, 행정문서와 지오메트리 연결, 중복/불확실성, 인간 승인 과정.

## Rivne — Energy Advisory AI Assistant

**문제:** 거주자·공동주택 대표·소상공인은 단열·창호·난방·전력 복원력 개선의 효과, 개략 비용, 금융지원을 비교하기 어렵고, 도시 전문가는 반복적인 1차 상담에 시간을 사용함.

**MVP(필수)**
1. 건물 용도·연식·층수·난방·고지서 등 단순 문답으로 건물 프로필 생성, 누락정보 표시.
2. 우크라이나 기준과 진단자료를 중심으로 몇 가지 에너지 개선 대안 비교.
3. 투자비·효과·회수기간의 **개략값** 계산(전문 에너지 진단의 대체가 아님).
4. 건물 정보·데이터 완전성·선택 대안·비용/효과·지원정보·다음 단계를 포함하는 출력 가능한 보고서 생성.

**선택 기능:** 시 담당자 보조모드, 자금지원 안내 강화, 중소기업·공공건물 전용 흐름.

**데이터 상태:** 시의 건물 기록과 과거 진단·개선 프로젝트 사례 등을 사용할 계획. 그러나 모든 공동주택/상가의 기록·소비량이 있는 것은 아니며 원본 제공과 접근권한은 추후 확인. XLSX/CSV, PDF/DOCX, 공식 우크라이나 기준과 사용자 직접 입력이 주요 자료.

**구현상 난제:** 개략 계산 공식 검증, 단위·가정의 투명성, 실제 요금·비용·지원제도 최신성, 추정치와 실측치 구별.

## 기술 재사용 방향 (가설 / 검증 전)

| 측면 | Skopje | Rivne |
|---|---|---|
| F.AIR 조사·검수 경험 | 근거 추출·문서 검토 | 규정 검색·보고서 검수 |
| V.AIR 공간정보 경험 | GIS 매칭·지도 검토 핵심 | 일반적으로 부차적 |
| 별도 전문 엔진 | 행정문서/좌표 매칭 | 규정기반 비용·효과 계산 |
| 최대 위험 | 원천문서와 GIS 연결 | 정확한 계산 가정과 데이터 품질 |

기존 제품의 운영 코드나 비공개 DB를 그대로 공개 저장소에 복제하지 않는다.

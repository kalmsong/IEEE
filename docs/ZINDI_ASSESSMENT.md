## 모델 및 도구 제한

- 공개적으로 이용 가능한 **생성형 모델 1개, 최대 30억(3B) 파라미터**.
- 문항당 **최대 15회 모델 호출, 생성 토큰 12,000개**. 재시도·자가검토 포함.
- 검색·OCR·임베딩·리랭킹·GIS·계산 도구는 추가 사용 가능하되 추가 생성형 모델을 호출해서는 안 됨.
- 유료 모델 API·신용카드를 요구하는 체험판 등 허용되지 않는 외부 서비스 사용 금지. 공개 오픈소스 도구 사용.
- Test 문항·Test 소스·그 복사본 및 파생물로 학습/파인튜닝/증류/자가학습 금지. **추론 시점의 인덱싱·검색·계산은 허용**.
- 승인된 자료 외의 데이터셋은 주최 측 사전 승인 필요. 신규 데이터 제안 마감 2026-11-30.

## 답변·평가

- Test ID마다 정확히 한 번씩 자연어 **영어 답변 + 근거**를 Markdown 형식으로 제출.
- 정확성·완전성 **80%**, 근거의 적합성 **20%**. 틀린 결론의 근거는 점수로 보상되지 않음.
- 교통·건물 에너지·녹지 **동일 비중** 집계.
- 공개 리더보드는 일부 문제만 점수 산정. 마감 후 감춰둔 문항까지 포함해 선택된 두 제출물의 최종 점수 비교.
- 제출 한도 **하루 1회, 총 20회**. 잠정 상위 100팀 등 코드 요청 시 **48시간 이내** 제출과 재현 검증 요구.

## 준비 순서

1. Zindi 로그인·참가 후 Train, Test, SampleSubmission, StarterNotebook 다운로드(팀 내부 승인 환경).
2. Train의 실제 질문 유형/분포·출처·정답구조 정량 분석.
3. 허용 모델 1개 + 문서 인덱싱·표 계산·GIS 분석·근거 체크를 조합한 기준 파이프라인 구현.
4. Train을 사용해 **정답 정확성 / 근거 정밀도 / 계산 단위 / 실행시간 / 비용·모델 호출 횟수** 검증.
5. 제출 재현성을 위해 모델 버전·시드·의존성·처리 로그와 소스 매니페스트 해시 기록.
